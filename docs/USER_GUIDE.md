# Guide utilisateur — Catalogue de recettes

## Bienvenue

Bienvenue dans **Catalogue de recettes**.

Cette application permet de consulter des recettes, de les rechercher, de les filtrer et de créer votre collection personnelle.

Vous pouvez ajouter vos recettes préférées à votre collection, indiquer votre avancement, attribuer une note et ajouter un commentaire personnel.

## Accéder à l'application

Ouvrez votre navigateur internet puis rendez-vous à l'adresse fournie par l'équipe du projet.

En local, l'adresse est généralement :

```text
http://localhost:5173
```

## Consulter le catalogue

Depuis la page d'accueil, vous pouvez accéder au catalogue de recettes.

Dans le catalogue, vous pouvez :

- consulter la liste des recettes disponibles ;
- utiliser la recherche pour trouver une recette par son titre ;
- filtrer les recettes selon leur catégorie ;
- consulter les recettes végétariennes ;
- consulter les recettes sans gluten ;
- accéder à la fiche détaillée d'une recette.

## Consulter une recette

Pour ouvrir une recette, cliquez sur son titre, son image ou le bouton permettant d'afficher les détails.

La fiche d'une recette présente notamment :

- le titre ;
- la description ;
- la catégorie ;
- le temps de préparation ;
- la difficulté ;
- les ingrédients ;
- les étapes de préparation ;
- les informations végétariennes ou sans gluten.

## Créer un compte

Pour créer votre espace personnel :

1. Cliquez sur **S'inscrire**.
2. Saisissez votre adresse email.
3. Choisissez un mot de passe robuste.
4. Confirmez la création du compte.

Le mot de passe doit respecter les règles affichées à l'écran :

- au moins 8 caractères ;
- une lettre minuscule ;
- une lettre majuscule ;
- un chiffre ;
- un caractère spécial.

Après votre inscription, vous pouvez vous connecter.

## Se connecter

La connexion se déroule en deux étapes.

### Étape 1 — Email et mot de passe

1. Cliquez sur **Se connecter**.
2. Saisissez votre adresse email.
3. Saisissez votre mot de passe.
4. Cliquez sur **Se connecter**.

Un code à six chiffres est alors envoyé à l'adresse email associée à votre compte.

### Étape 2 — Code de vérification

1. Consultez votre boîte de réception.
2. Relevez le code à six chiffres reçu.
3. Saisissez ce code dans la page de vérification.
4. Cliquez sur **Vérifier**.

Le code est temporaire et ne peut être utilisé qu'une seule fois.

Si vous ne recevez pas le code :

- vérifiez votre dossier Spam ou Courrier indésirable ;
- vérifiez l'adresse email utilisée ;
- recommencez la connexion pour demander un nouveau code.

## Réinitialiser un mot de passe oublié

Si vous avez oublié votre mot de passe :

1. Sur la page de connexion, cliquez sur **Mot de passe oublié ?**.
2. Saisissez l'adresse email de votre compte.
3. Cliquez sur **Recevoir un code**.
4. Consultez votre boîte email.
5. Saisissez le code reçu.
6. Choisissez un nouveau mot de passe robuste.
7. Confirmez votre nouveau mot de passe.
8. Cliquez sur **Changer le mot de passe**.
9. Connectez-vous avec votre nouveau mot de passe.

Le code de réinitialisation expire après quelques minutes et ne peut être utilisé qu'une seule fois.

Si le code ne fonctionne plus, recommencez la demande de réinitialisation afin d'en recevoir un nouveau.

## Ajouter une recette à ma collection

Vous devez être connecté pour utiliser votre collection personnelle.

Depuis la fiche d'une recette :

1. Cliquez sur le bouton pour ajouter la recette à votre collection.
2. La recette est ajoutée à votre espace personnel.
3. Accédez à la page **Ma collection** pour la retrouver.

## Gérer ma collection

Dans votre collection, vous pouvez organiser chaque recette selon votre progression.

Les statuts disponibles sont :

| Statut | Signification |
|---|---|
| À découvrir | Vous souhaitez essayer cette recette plus tard |
| En cours | Vous êtes en train de préparer ou tester la recette |
| Terminé | Vous avez déjà réalisé cette recette |

Pour modifier une recette de votre collection :

1. Ouvrez votre collection.
2. Sélectionnez le statut souhaité.
3. Ajoutez éventuellement une note.
4. Ajoutez éventuellement un commentaire.
5. Enregistrez les modifications si un bouton de validation est proposé.

## Ajouter une note et un commentaire

Vous pouvez personnaliser chaque recette ajoutée à votre collection.

Vous pouvez :

- attribuer une note ;
- écrire un commentaire ;
- noter ce que vous avez modifié ;
- garder une idée pour la prochaine préparation ;
- mémoriser votre avis sur une recette.

Exemples de commentaires :

```text
Très bon avec des légumes supplémentaires.
Réduire le temps de cuisson de cinq minutes.
À refaire pour un repas en famille.
```

## Consulter mes statistiques

La page **Statistiques** présente une synthèse de votre collection personnelle.

Vous pouvez notamment y consulter :

- le nombre total de recettes enregistrées ;
- la répartition des recettes selon leur statut ;
- votre note moyenne, lorsque des notes ont été ajoutées.

## Se déconnecter

Pour vous déconnecter :

1. Cliquez sur le bouton ou le lien de déconnexion.
2. Votre session est supprimée du navigateur.
3. Vous devrez recommencer la connexion avec votre email, votre mot de passe et le code reçu par email.

## Résolution des problèmes

### Je ne peux pas me connecter

Vérifiez :

- votre adresse email ;
- votre mot de passe ;
- que vous saisissez bien le dernier code reçu ;
- que le code n'a pas expiré ;
- que le code comporte bien six chiffres.

### Je n'ai pas reçu de code par email

Vérifiez :

- la boîte de réception ;
- le dossier Spam ou Courrier indésirable ;
- l'adresse email saisie ;
- que vous attendez quelques instants avant de recommencer.

### Mon code est refusé

Un code peut être refusé s'il :

- est incorrect ;
- a expiré ;
- a déjà été utilisé ;
- a été saisi trop souvent de manière incorrecte.

Dans ce cas, recommencez la connexion ou la réinitialisation afin d'obtenir un nouveau code.

### Je ne vois pas ma collection

Vous devez être connecté pour consulter votre collection personnelle.

Reconnectez-vous puis ouvrez la page **Ma collection**.

## Conseils de sécurité

- Ne partagez jamais votre mot de passe.
- Ne communiquez jamais votre code de vérification à une autre personne.
- Utilisez un mot de passe différent de ceux employés sur vos autres sites.
- Déconnectez-vous si vous utilisez un ordinateur partagé.
- Vérifiez toujours l'adresse de l'expéditeur avant de suivre une demande par email.
